# Счётчик (React Native + Expo)

Минимальное мобильное приложение-счётчик.

## Запуск

Установка зависимостей:

```powershell
npm install
```

Запуск Metro и Expo:

```powershell
npx expo start
```

Откройте приложение **Expo Go** на телефоне и отсканируйте QR-код или нажмите `a` (Android) / `i` (iOS) в терминале для эмулятора.

## Функции

- Крупное число по центру (начальное значение 0)
- Кнопка **+** — увеличивает значение на 1
- Кнопка **Сброс** — сбрасывает значение в 0
